## About me

I'm a full-stack developer with a focus on PHP and Laravel. I work on applications where several teams rely on the same data, such as charter bookings, vehicle availability, and product catalogs. My work spans data modeling, REST API design, authentication, role-based access control, and the dashboards teams use to manage those workflows.

I also maintain existing applications. In practice, that means tracing slow pages to the underlying SQL, moving long-running tasks to queues, and adding features while preserving the workflows customers and staff already depend on.
